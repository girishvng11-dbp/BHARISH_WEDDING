# Bhavana & Girish V N — Wedding Invitation

A lightweight static invitation website for the wedding celebrations on 20 and 22 November 2026.

## Hosting

The site is configured to deploy to GitHub Pages from the `main` branch using GitHub Actions. Once Pages is enabled for the repository, updates pushed to `main` publish automatically.

Expected address: https://girishvng11-dbp.github.io/BHARISH_WEDDING/

The website is plain HTML, CSS, JavaScript, and local media files; no build step or package installation is needed.

Wedding music: “South India Nadaswaram Thavil – Kappi Raga” by Saseendran, shared through the [Pixabay Content License](https://pixabay.com/service/license-summary/). Track source: [Pixabay](https://pixabay.com/music/india-south-india-nadaswaram-thavil-kappi-raga-358257/). The track is bundled locally as `assets/south-india-nadaswaram.mp3` and starts only after a guest opens the invitation.
